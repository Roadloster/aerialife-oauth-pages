Hermes Gmail Readonly

Hermes Gmail Readonly is a private, owner-operated application used only by authorized account holders to retrieve their own Gmail messages as read-only evidence for personal mail review and briefing workflows.

What the application does

  • Lists messages in an authorized Gmail account.
  • Reads message headers, bodies, and attachments when requested by the account owner.
  • Uses the data only for private mail evidence and briefing workflows.

What the application does not do

  • It does not send, delete, modify, label, or mark email as read.
  • It does not sell Gmail data.
  • It does not provide Gmail data to advertisers.
  • It is not offered as a public email service.

Authorization

Access requires explicit Google OAuth consent from each account owner. Authorization may be revoked at any time from the account owner’s Google Account security settings.
